# kOSMos

A quiet, fast map of the world, made from OpenStreetMap.

One map, one search field, one location button. Everything else is the map.

## What it does

Designed from first principles: a map app answers six questions, and kOSMos answers each in exactly one way.

| Question                | Answer                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| ----------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| What is the world like? | A vector map, light or dark with the system, a globe when zoomed out, 3D buildings when tilted                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| Where is X?             | Search (as you type, biased to what you are looking at); or a kind of place (restaurants, groceries, museums, toilets, ATMs, … in English or German), offered above the names and chosen by tap or Enter, found in the map's own tiles (full detail even when zoomed out; a very wide view searches its middle; nameless toilets, cash machines, car parks and playgrounds too), nearest to you when you are in view, else to the middle of the map you see, without a search server; the search key shows them all, dots open their place, and after you move the map one tap searches the new area (in view only, without zooming). A search stays while a route is open (its dots step aside) and Back ends it                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| Where am I?             | Your dot appears on opening once location is allowed (the app never asks before you tap). The location button, low on the right within thumb reach: first tap follows you north-up, the second turns the map with the compass; a beam on your dot shows where the phone points, lying flat or held up like a torch                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| What is here?           | Tap a label, or long-press (right-click) anywhere: name, address, opening hours (open now, until when, for places on about your clock; the week in your language and clock), phone, website, coordinates, share, route. A label's details are the nearest place of its name, never another branch's; else the spot's own address                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| How do I get there?     | Route from the place card, in the travel mode used last: car, bike, walk or public transport (connections with lines, platforms, delays, every stop on tap; leave now or later), with alternatives, steps, changeable start and destination; "Open in…" hands off to another app ; long-press the map for a new start or destination; with no route it says by which mode, and the other ways are named, one tap away                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| Take me there           | Start: turn-by-turn on the device with spoken prompts that say how far ("In 300 metres, turn right …"; driving remembers voice on or off, on foot, by bike and on public transport each trip starts silent), lane guidance where the lane matters (small ahead, large near the turn), heading-up camera (the compass takes over when walking or standing), current speed, automatic rerouting that leaves in the direction you are going (quiet while off the route, the way back shown; a poor GPS fix never skips a turn), and a map that follows the sun (light by day, dark after sunset and in tunnels, whatever the phone is set to). By public transport: walk to the stop turn by turn, when the line leaves, stops left and "get off at the next stop", by GPS above ground and by the timetable underground; shortly before boarding one check of the vehicle's own trip brings the live departure, platform and stops; a new platform, a delay, a cancellation or a missed departure is said. The ride ends at your stop, not the one before, and arrival needs you there, not just the timetable. Tapping the banner shows the whole trip, every stop and turn. End asks for a second tap (back too) and is always there, also while a route is still on its way; on arrival it becomes Done, and guidance ends by itself after a minute, back at the destination's card. Off the route the map stays with you. A late train keeps guiding by its position; a missed or cancelled one offers a new connection, from the stop when the position is old. Routes open in the travel mode used last. Android keeps guiding with the screen off; in the browser keep the app open |

Distances in kilometres, or miles and feet (US) and miles and yards (UK) by the phone's region. English or German by the browser; times, weekdays and the voice follow its exact locale (12- or 24-hour clock). Phones held sideways get the side-by-side layout: one column for cards and guidance, the map beside it, the arrow low so the road ahead fills the view. Notes sit above the panel within the thumb's reach (beside it on wide screens) and never cover a control; the one gesture nothing shows, long-press, is said once, the first time the map shows streets.

Works with a keyboard and screen readers: a card's heading takes focus as it opens and closing goes back to the search, arrow keys choose the travel mode and route, notes are announced, and camera moves and label fades stop when the system asks for reduced motion.

The view is kept between sessions and in the URL (`#map=zoom/lat/lng/bearing/pitch`), so any view is a link.

## Privacy

No account, no analytics, no tracking. Your location leaves the device only as the start of a route you ask for. The app talks to exactly five services:

| Service                                                                | For                                     | Sends                                                                                                                                        |
| ---------------------------------------------------------------------- | --------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------- |
| [OpenFreeMap](https://openfreemap.org)                                 | Map tiles, glyphs for non-Latin scripts | Tile coordinates of what you view                                                                                                            |
| [Photon](https://photon.komoot.io) by komoot                           | Search, address lookup                  | Search text, map centre; a tapped label's name and point; the point you long-press                                                           |
| [Valhalla](https://valhalla1.openstreetmap.de) by FOSSGIS              | Routing                                 | Route start (your location, when you ask for a route), destination and travel mode                                                           |
| [Transitous](https://transitous.org)                                   | Public transport                        | Start, destination and departure time of a public transport route you ask for; while you follow it, the vehicle's trip id for one live check |
| [Nominatim](https://nominatim.openstreetmap.org) by the OSM Foundation | Opening hours, phone, website           | The OpenStreetMap id of the place card you open; a search's text only when Photon does not answer                                            |

## Android permissions

Location, precise or approximate (while navigating it runs in a foreground service with a notification, so directions continue with the screen off), notifications (asked for on the first navigation, Android 13+, only for that notification), internet. Nothing runs in the background outside navigation. Location comes from Android's own location service (GPS, or the network), so the app needs no Google Play services and works on de-Googled phones. Release builds write nothing about your position to the system log.

## Run locally

```sh
npm ci
npm run dev        # http://localhost:5173
npm run check      # typecheck, lint, format, unit tests
npm run build && npm run e2e
```

E2E tests run against a synthetic world (`e2e/fixtures/`): generated vector tiles and canned search answers, so they need no network. `SHOTS=<dir> npm run e2e` also writes the screenshots for design review.

Android: `npm run android:sync`, then open `android/` in Android Studio or run `./gradlew assembleDebug` there.

## Release

- **Web:** every push to `main` deploys to GitHub Pages.
- **Android:** bump `version` in `package.json` and push to `main`. The Android workflow builds the APK and smoke-tests it on an emulator; a separate job, which never runs npm or Gradle, then signs it, checks the signer against the fingerprint above and publishes `v<version>` with the APK. versionCode = major·10⁷ + minor·10⁵ + patch·10³.
- Signing secrets: `ANDROID_KEYSTORE_BASE64`, `ANDROID_KEYSTORE_PASSWORD`, `ANDROID_KEY_ALIAS`, `ANDROID_KEY_PASSWORD`. Without them CI builds a debug-signed APK artifact and publishes nothing.

## Stack

TypeScript, React 19, Vite, MapLibre GL JS 6, vite-plugin-pwa, Capacitor 8. Map style written from scratch for the OpenMapTiles schema (`src/core/style.ts`), labels set in self-hosted Inter.
